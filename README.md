# Контент-Цех · Недвижимость

Личная платформа контент-производства для строительной компании / агентства недвижимости. Один файл — `index.html` — работает офлайн, без серверов и зависимостей: откройте его в любом браузере (на компьютере или телефоне).

## Что внутри

| Лист | Раздел | Что даёт |
|------|--------|----------|
| Л1 | **Рубрикатор** | 10 рубрик-«несущих стен» с психологическим триггером и частотой выхода каждой |
| Л2 | **Банк идей** | 70 конкретных роликов с фильтрами, поиском, отметкой «снято» (сохраняется в браузере) и рулеткой «Что снимать сегодня» |
| Л3 | **Хуки** | Библиотека первых трёх секунд по 4 механикам + генератор хуков |
| Л4 | **Психология** | 10 приёмов нативных продаж — как продавать, не продавая |
| Л5 | **Система** | Формула виральности, недельная сетка выходов, правила цеха |

## Как пользоваться

1. Начните с рубрик Р-01 (Ревизор), Р-03 (Угадай цену) и Р-06 (Строй-ASMR) — они быстрее всего дают охваты.
2. Каждое утро съёмочного дня жмите «Что снимать сегодня» на листе 2.
3. Держите пропорцию 80/20: восемь виральных роликов на два продающих.
4. Отмечайте снятое — прогресс хранится в localStorage вашего браузера.
