> Это основа личности бота. Дополняй свободно: сюда можно вставить экспорт
> памяти из ChatGPT / Claude («Что ты обо мне помнишь?»), заметки, цели.
> Бот перечитывает файл при каждом сообщении — перезапуск не нужен.

## Что известно из рабочих чатов
- Саи — соло AI-видео креатор. Строит личную систему «НЕЙРОПОТОК» — рабочий стол
  для производства AI-видео: банк мастер-промптов по механикам (morph, slice, loop,
  scale и др.), версии промптов v1→v2→v3, ночные «дропы» идей.
- До этого строил «Контент-Цех» для недвижимости: рубрикатор, банк из 70 идей
  роликов, хуки, психология нативных продаж, правило 80/20 (виральное / продающее).
- Работает системно и по ночам: регулярные ночные дропы, постоянная доработка.
- Склонен строить инструменты и системы вокруг контента — иногда вместо того,
  чтобы выпускать сам контент (гипотеза, проверять вопросами, а не утверждать).
- Мыслит на русском, любит краткость, конкретику и практику.
