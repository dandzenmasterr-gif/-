# Высший Я — Telegram-бот

Собеседник-«высший я» для Саи: задаёт точные вопросы про настоящий момент, куда это ведёт
и что делать сейчас. Основа — память: `memory/sai_profile.md` + инсайты, которые бот сам
выжимает из разговоров (`data/insights.md`), и заметки через `/remember`.

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # вписать TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY
python bot.py
```
Без `ANTHROPIC_API_KEY` бот работает в офлайн-режиме: задаёт вопросы и пишет дневник (`data/journal.md`).

Первый, кто напишет боту, становится владельцем (`data/owner.txt`) — остальным доступ закрыт.

## Команды
- `/session` — глубокая сессия: настоящее → к чему ведёт → чего хочу → следующий шаг
- `/remember <текст>` — запомнить важное
- `/memory` — что бот о тебе помнит
- `/reset` — новый разговор (инсайты сохраняются)

## Как усилить память
Попроси ChatGPT/Claude: «Выпиши всё, что ты обо мне помнишь» — и вставь ответ в
`memory/sai_profile.md`. Бот перечитывает файл на каждом сообщении.
